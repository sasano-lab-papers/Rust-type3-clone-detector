# Rust Type-3 Clone Detector

トークン情報と抽象構文木情報を用いた  
Rustコードクローン検出ツール

</div>

---

## 概要

本プログラムは，Rustプロジェクトに含まれる関数およびメソッドを対象として，Type-1からType-3までのコードクローンを検出します。

対象プロジェクトから関数およびメソッドを抽出した後，トークン情報に基づいてクローン対を分類します。トークン情報のみでは判定できない対については，抽象構文木を生成し，部分木ハッシュおよび特徴ベクトルに基づいて判定します。

## 処理の流れ

```text
関数およびメソッドの抽出
          ↓
トークンに基づく分類
          ↓
抽象構文木に基づく分類
          ├─ 部分木ハッシュによる判定
          └─ 特徴ベクトルによる判定
```

## リポジトリ構成

```text
Rust-Type3-Clone-Detector/
├─ Cargo.toml
├─ README.md
├─ crates/
│  ├─ function_extractor/
│  │  ├─ Cargo.toml
│  │  └─ src/
│  │     └─ main.rs
│  └─ ast_builder/
│     ├─ Cargo.toml
│     └─ src/
│        └─ main.rs
└─ scripts/
   ├─ token_filter.py
   ├─ ast_hash_detection.py
   ├─ ast_vector_detection.py
   └─ run_pipeline.bat
```

## 各構成要素

| 構成要素 | 内容 |
|---|---|
| `crates/function_extractor` | Rustファイルから関数およびメソッドを抽出し、字句解析によりトークン列と行情報を生成します。 |
| `scripts/token_filter.py` | N行ブロックのハッシュ値に基づく類似度とトークン重複度に基づいて、関数およびメソッドの対を分類します。 |
| `crates/ast_builder` | 抽象構文木に基づく分類の対象となる対について、抽象構文木を生成します。 |
| `scripts/ast_hash_detection.py` | 部分木ハッシュに基づく類似度を計算し、クローン判定を行います。 |
| `scripts/ast_vector_detection.py` | 特徴ベクトルに基づくJaccard係数を計算し、クローン判定を行います。 |
| `scripts/run_pipeline.bat` | 関数およびメソッドの抽出から各判定までの処理を順番に実行します。 |

## 実行方法

リポジトリをダウンロードまたはクローンした後、リポジトリのルートディレクトリで次のコマンドを実行します。

```bat
scripts\run_pipeline.bat "<解析対象のRustプロジェクト>" "<出力先ディレクトリ>"
```

第1引数には解析対象のRustプロジェクトのパス、第2引数には中間データおよび検出結果の出力先を指定します。

処理が完了すると、関数およびメソッドの抽出結果、トークンに基づく分類結果、抽象構文木の情報、および各判定結果が指定した出力先に保存されます。

## 主な設定値

| 項目 | 値 |
|---|---:|
| 最小トークン数 | 50 |
| N行ブロックの行数 | 3 |
| SR候補閾値 | 0.15 |
| トークン重複度候補閾値 | 0.50 |
| SR判定閾値 | 0.70 |
| トークン重複度判定閾値 | 0.70 |
| AT類似度閾値 | 0.65 |
| AST Dice類似度閾値 | 0.70 |
| AST特徴ベクトルの深さ | 1 |
| Jaccard類似度閾値 | 0.75 |
